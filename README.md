# Balance — все платформы

В архиве находятся нативные приложения личных финансов и общий self-hosted сервер синхронизации.

| Папка | Назначение |
| --- | --- |
| `Balance` | iOS 17+, macOS 14+ и watchOS 10+, SwiftUI + SwiftData |
| `BalanceAndroid` | Android 8.0+, Kotlin + Jetpack Compose + Room |
| `BalanceServer` | Go-сервер авторизации и синхронизации со встроенным web-приложением |

Все пять клиентов — iOS, macOS, watchOS, Android и web — используют одну модель данных и один протокол сервера: операции, пользовательские категории, бюджеты, удаления, регистрация, вход, refresh-токены и постраничная двусторонняя синхронизация. Web-интерфейс открывается по адресу запущенного сервера и не требует отдельной установки.

Инструкции по запуску находятся в `Balance/README.md`, `BalanceAndroid/README.md` и `BalanceServer/README.md`.
